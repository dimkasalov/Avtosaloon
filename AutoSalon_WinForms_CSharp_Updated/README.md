# AutoSalon — Windows Forms / C# / .NET 8

## Запуск
1. Откройте `AutoSalon.sln` в Visual Studio 2022.
2. Восстановите NuGet-пакеты.
3. Выполните `Сборка → Пересобрать решение` и запустите через F5.

Стандартные учётные записи: `admin / admin` и `manager / manager`.

## Обновление форм
- В добавлении автомобиля есть вкладки «Новый» и «С пробегом (БУ)».
- Марка, модель, кузов, цвет, двигатель, коробка, привод, состояние и статус выбираются из выпадающих списков.
- ТО и ремонт: автомобиль и тип обслуживания выбираются из списков; также есть готовые варианты работ и специалистов.
- Юридические проверки: автомобиль, проверяющий и результат выбираются из списков; наличие залога, ареста и ограничений задаётся флажками.
- Продажи и договоры: автомобиль и клиент выбираются по понятным подписям, стоимость подставляется из карточки автомобиля, продавец и статус выбираются из списков.
- Добавлена миграция SQLite для существующей базы: новое поле типа автомобиля `VehicleType` добавляется автоматически.

База данных `autosalon.db` создаётся рядом с запускаемым приложением. Перед заменой проекта рекомендуется сохранить резервную копию существующей базы.
